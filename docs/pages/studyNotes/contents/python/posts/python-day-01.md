# Python-Day-01
print()相當於JS的console.log，是python用來Debug列印出來的地方，但寫法有點不太一樣他可以直接寫print("文字" + "文字")，但無法print("文字" + 數字)這樣會報錯，可以用一個","這樣的逗號把它隔開print("文字", 數字)這樣才可以，也可以用其他的方式，但現在還沒學習到，日後會在其他篇補上。

input()相當於JS的prompt，會停在終端機等你輸入值，只是python的命名更直接。

變數宣告，在python的宣告中不需要var、let、const，只需要直接命名就好，例如：let num = 10 就直接寫成 num = 10 這樣就好了，至於值很容易就會被替代掉這件事目前還沒學到，在之後的學習日誌再寫。
